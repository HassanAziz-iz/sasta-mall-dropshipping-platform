# Security Policy

## Important deployment warning

Sasta Mall includes public demo admin credentials for local setup:

- Username: `admin`
- Password: `admin123123123`

These credentials are published in the README for convenience. Change the password immediately before exposing an instance to the public internet. Set a unique, strong `SESSION_SECRET` in your private `.env` file.

## Reporting a vulnerability

Please do not publish sensitive vulnerability details in a public issue. Contact the repository maintainer privately using the contact method listed on the GitHub repository profile.
